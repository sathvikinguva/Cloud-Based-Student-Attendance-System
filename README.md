# Cloud-Based-Student-Attendance-System

A cloud-based student attendance management system that uses facial recognition technology to automatically detect and record student attendance in classrooms.

## Features
- Automated attendance using facial recognition
- Real-time face detection using OpenCV
- Secure identity verification using ArcFace embeddings
- Cloud-based data storage and management
- Scalable system for educational institutions

## Technologies Used
- Python
- OpenCV
- ArcFace
- Machine Learning
- Cloud Computing

## How It Works
1. The system captures student faces through a camera.
2. Facial features are extracted using deep learning models.
3. The system compares facial embeddings with stored student data.
4. If a match is found, attendance is automatically recorded.
